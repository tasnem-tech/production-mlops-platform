MACHINE LEARNING ENGINEERING · PORTFOLIO PROJECT

Building smarter
ML systems.

A modular machine learning engineering prototype for synthetic customer churn prediction, featuring reproducible training, model evaluation, a FastAPI prediction service and a Streamlit interface.

Explore Source Code ↗ Explore Architecture

Platform Capabilities

Exploring the foundations of reproducible machine learning software.

01 · Machine Learning

Reproducible synthetic data generation, Scikit-learn training pipelines and classification.

02 · Model Evaluation

Held-out testing using accuracy, ROC-AUC and average precision metrics.

03 · REST API

FastAPI prediction endpoint with Pydantic input validation and API documentation.

04 · Interactive Interface

Streamlit customer-input controls for simulated churn probability predictions.

05 · Automated Testing

Pytest-based tests for model behaviour, reproducibility and API responses.

06 · Containerisation

Docker configuration for packaging the FastAPI inference service.

System Architecture

An overview of the intended prediction workflow.

Synthetic Data → Preprocessing → Model Training → Evaluation → Model Artifact → FastAPI → Streamlit

Technology Stack

Python Scikit-learn Pandas NumPy FastAPI Streamlit Pydantic Pytest Docker GitHub

Project Status

This is an educational prototype currently under development. The repository's Python package structure requires correction before the full application can run as documented. The website is a static project showcase, not a live prediction dashboard. All modelling uses synthetic data.
